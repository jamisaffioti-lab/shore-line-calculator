# shore-line-calculator

A one-page quote calculator for Shore Line Renovations, a five-person renovation company in Monmouth County, NJ.

It gives homeowners a clear starting price for bathroom, kitchen, and deck projects, with no sign-up and no sales pitch.

## What it does

- Lets you pick a job type: bathroom, kitchen, or deck.
- Adds up the options you choose.
- Shows a starting price in plain numbers.

## How to use it

1. Open `index.html` in any web browser. No install or build step.
2. Choose the job type.
3. Select the options that fit the project.
4. Read the starting price shown at the bottom of the page.

To share it with a customer, send them the page link or screenshot the result.

## About the prices

All prices are **starting prices** taken from the Shore Line Renovations 2026 price list. They are not a final quote. The final price depends on a walkthrough of the space, the materials chosen, and the scope of work.

When the price list changes, update the prices in the calculator to match it.
